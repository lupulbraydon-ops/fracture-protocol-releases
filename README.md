# Fracture Protocol — release feed

Download the newest **`FractureProtocol-vX.Y.Z-win-x64.zip`** from
[Releases](https://github.com/lupulbraydon-ops/fracture-protocol-releases/releases/latest),
unzip it anywhere (e.g. `C:\Games\Fracture Protocol`), and run **`Fracture Protocol.exe`**.

Windows 10/11, 64-bit. First launch: SmartScreen may say "Windows protected your PC"
(the build is unsigned) — click *More info → Run anyway*.

Installed copies check this feed on every start and offer newer builds with a
one-click **Update & restart** button, so you only ever need to download once per PC.
LAN games require every PC to run the same version.

`READ ME FIRST.txt` inside the zip has the controls and LAN instructions.
